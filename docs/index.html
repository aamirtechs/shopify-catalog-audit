Free open source tool

shopify-catalog-audit

Audit a Shopify or WooCommerce product CSV export for the catalog problems that cost sales, and get a short review-first fix list. The tool only reports, it never modifies or deletes a row.

View source on GitHub

Run it in your browser

Runs fully in your browser, files never leave your device.

Drag and drop the file onto this box, or use the picker. A standard Shopify product CSV export, one row per variant.

Audit summary


    

  



    
What it does

    

      
Duplicate SKU and duplicate barcode detection across the export, with the first occurrence treated as the original

      
Near-duplicate titles across different handles, and conflicting titles carried by the same handle

      
Orphaned variant rows whose handle never has a titled parent row

      
Missing image, missing image alt text, blank or zero price, and missing weight checks

      
Review-first output: review.csv with a merge or fix suggestion per problem, plus a summary report. Fixing stays a human decision in the store admin

    

  

  

    
Install and usage

    
Requires Node.js 20 or later. There are no dependencies to install.

    
git clone https://github.com/aamirtechs/shopify-catalog-audit.git
cd shopify-catalog-audit
node src/cli.js --input examples/products.csv --out review.csv --report report.md

    
The audit reads a standard Shopify product CSV export, one row per variant, exactly as Shopify produces it. Re-export and re-run after fixing to confirm the list is clear.
